Project Overview

The Idea

Your color palette has been waiting in a museum since 1665.

Instead of reusing the same predictable startup palettes from Pinterest or Mobbin, Pastiche captures real visual tension and harmony directly from art history. Inspired by the balanced, physical color choices of 17th-century painters like Vermeer and my great-grandfather, Pt. Bhawani Dutt Shastri.

The Problem

Designers default to the same digital palettes. The result is an industry of interfaces that look identical.

The Insight

Masters spent decades perfecting color balance. That knowledge sits freely in public museum archives. No one had made it usable inside a design tool.

Backend Strategy

No databases. No servers. No maintenance costs. Everything runs in the browser.

Pastiche runs entirely inside Figma's local iframe. The only cloud infrastructure is a zero-maintenance Cloudflare Worker used strictly to bypass browser CORS blocks when loading museum images.

Inside Figma (Local)
  • ui.html — runs k-means clustering in the browser
  • code.js — executes Figma canvas interactions
  • Figma File — generates layers and variable tokens
External Services (Public Cloud)
  • GitHub — hosts 82MB NGA painting catalog
  • Cloudflare Worker — image proxy for CORS bypass
  • NGA Server — delivers source JPEG files

Data never leaves the file. The proxy handles public museum metadata, never user design files.

End-to-End Data Flow

From opening the panel to generating tokens in under 3 seconds.

01 — Init
Load Catalog

UI opens. Pulls 82MB NGA catalog CSV from GitHub. Parses 5,800 painting records directly into RAM.

02 — Fetch
Stream Image

User clicks a painting. Public ID is passed to Cloudflare proxy. Worker streams the museum JPEG back to the plugin.

03 — Math
Extract Colors

JPEG is drawn to canvas. Local k-means algorithm isolates dominant, accent, and neutral color hexes from the painting.

04 — Write
Build Tokens

Color array is sent to code.js. Figma API alters layer fills and builds a complete Variable Token System in the file.

Result
Zero Server Cost

Entire system operates within free cloud serverless tiers. $0.00 per month infrastructure cost.

Privacy
No Tracking

No cookies, no user accounts, no file scraping. Writes are purely additive and only fire on explicit designer action.

Key Features

Three layers of capability built into one plugin panel.

01 — Painting Library

5,800 masterworks. Instantly searchable.

Featured carousel of prominent global works for instant generation. In-memory keyword search across the full NGA open-access catalog. Results in a clean grid of 24 thumbnails. Select any artwork and see the full name, artist, year, and original medium.

02 — Color Extraction Engine

Relationship-driven sampling, not just dominant colors.

Rather than pulling the most common pixels, the k-means algorithm identifies structurally distinct shades — isolating dominant warmth, cool accents, and neutral anchors. Builds a full 5-token palette plus complete brand, secondary, and neutral scales. Slight randomness on re-runs keeps the palette alive while staying faithful to the artwork.

03 — Canvas Interaction and Export

Deep layer support. Developer-ready export.

Recursively walks chosen vector selections to paint deeply nested children groups, fills, and borders. Creates organized Figma Variable Collections directly in the file. Exports as JSON Tokens and native CSS custom properties for immediate production use.
